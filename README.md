## 🌟 About Yzak Fashion Store

**Yzak Fashion Store** is a premium e-commerce fashion platform built for the Ethiopian market. With branches in **Dire Dawa** and **Hawassa**, Yzak brings high-quality, stylish clothing directly to customers through a seamless online admin experience.

Designed with simplicity and elegance in mind, the platform lets store owners manage their entire inventory, product catalog, and customer orders — all in one place.

---

## ✨ Features

| Feature | Description |
|---|---|
| 👕 **Category Management** | Create and organize product categories with ease |
| 👗 **Product Catalog** | Add items with name, description, price (ETB), size, color, SKU, and images |
| 🛒 **Order Management** | Track and manage all customer orders in real time |
| 🔐 **Secure Admin Login** | Password-protected admin dashboard |
| 📊 **Dashboard Stats** | Live overview of total products, categories, and orders |
| 🇪🇹 **ETB Currency Support** | Prices displayed in Ethiopian Birr (ETB) |

---

## 🖥️ Admin Panel

The admin dashboard gives store managers full control over the store:

```
📌 Dashboard Overview
   ├── Total Products Counter
   ├── Active Categories Counter
   └── Total Orders Counter

📂 Category Manager
   ├── Add new categories
   └── Assign categories to products

🛍️ Product Manager
   ├── Product Name & Description
   ├── Price (ETB), Stock Quantity
   ├── SKU, Size & Color
   ├── Product Image URL
   └── Category Assignment

🧾 Order Manager
   └── View & manage all customer orders
```

## 📦 Product Fields

When adding a fashion item, you can fill in:

- **Product Name** — The item title
- **Description** — Details about the product
- **Price (ETB)** — Price in Ethiopian Birr
- **Stock Quantity** — How many items are available
- **SKU** — Unique product code for inventory tracking
- **Size** — Available size (S, M, L, XL, etc.)
- **Color** — Product color
- **Image URL** — Link to the product photo
- **Category** — Assigned product category

---

## 🔒 Security

- Admin login is required to access the dashboard
